# Ai_Chat (Beta 测试版本)

## 分支说明
当前分支为 `beta` 分支，仅用于功能测试，**请勿在生产环境中使用**！

## 测试核心功能
本次 Beta 版本重点测试以下功能：
- **向量数据库上下文检索**
  - 实现基于向量数据库的对话上下文精准检索能力
  - 支持多轮对话的上下文关联匹配
  - 优化检索效率和召回率（测试阶段）

## 已知风险与限制
⚠️ **重要提醒：当前版本不稳定，存在以下风险**
1. **插件冲突风险**：向量数据库检索功能与部分插件（如动态提示词注入插件、时间观念插件）存在兼容性问题，可能导致程序崩溃或检索结果异常；
2. **功能稳定性问题**：上下文检索的准确率、响应速度尚未优化，极端场景下可能出现检索结果缺失、重复或错误；
3. **数据安全风险**：测试版本未做完整的数据校验，向量数据库的数据写入/读取可能存在异常，请勿接入生产环境的数据库。

## 使用建议
1. 测试环境：建议在独立的测试服务器/本地环境部署，避免与正式服务共用资源；
2. 数据隔离：测试时使用模拟数据或测试数据集，禁止使用真实业务数据；
3. 问题反馈：如发现插件冲突、检索异常等问题，请在仓库 Issues 中提交详细的复现步骤和日志；
4. 版本回退：若遇到严重问题，可切换到 `main` 分支使用稳定版本。
